# 平湖绒仓 V1 演示

这是“平湖绒仓”老板端/客户经理后台的静态演示页面。

## 演示内容

- 老板端首页：资产、行情、待处理事项
- 羽绒行情：50白鸭绒、90白鸭绒、95白鸭绒、50白鹅绒、90白鹅绒、95白鹅绒
- 仓单：仓单详情、检测报告入口、提货/授信入口
- 锁价：按吨锁价、参考价、预付测算、风险提示、提交进度
- 提货：按吨输入，自动换算公斤和包数，支持本地仓/外地仓送货到厂
- 授信：基于仓单货值测算额度
- 我的：企业认证、收货地址、记录、文件、服务中心入口
- 客户经理后台：待处理申请、仓单、客户、文件
